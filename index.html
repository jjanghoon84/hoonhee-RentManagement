  1. Firebase 콘솔에서 새 프로젝트를 만드세요. (무료 Spark 요금제로 충분해요)
  2. Authentication → 로그인 방법에서 이메일/비밀번호를 사용 설정하세요.
  3. Authentication → 사용자 탭에서 함께 쓸 계정 2개를 추가하세요.
  4. Firestore Database를 만들고(프로덕션 모드), 규칙 탭에 firestore.rules 내용을 붙여넣고 게시하세요.
  5. 프로젝트 설정 → 내 앱 → 웹 앱(</>) 추가 후 나오는 firebaseConfig 값을 복사하세요.
  6. 복사한 값을 firebase-config.js에 붙여넣고 GitHub에 올리세요.

자세한 단계별 방법은 저장소의 설치가이드.md를 참고하세요.
